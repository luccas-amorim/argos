# STF

O plano do STF mora no AtlasPen, que é quem precisa dele:
[`.superpowers/specs/2026-10-04-stf.md`](https://github.com/luccas-amorim/atlaspen/blob/main/.superpowers/specs/2026-10-04-stf.md).

Do lado do Argos, o que o plano pede e já existe é o adaptador `lista`
(`argos/fontes/lista.py`): tabela HTML que muda devagar, como teses de repercussão geral e
súmulas, com id que muda quando a linha muda. O resumo do que se mediu sobre as fontes
judiciais está em [jurisprudencia.md](jurisprudencia.md).
